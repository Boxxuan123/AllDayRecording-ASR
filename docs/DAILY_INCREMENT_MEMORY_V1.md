电脑人物页的“选取并更新”仍是唯一新增缓存入口。相同日期与联系人再次更新时，读取所选三天内缓存的新消息；普通 GET 和手机同步只复核已保存证据，不扩充输入或新增后台调度。一次主动更新为一次冻结读取加发布前后两次校验，均受三天、三联系人、5000 条缓存上限约束；不调用模型、ASR、声纹、每日回顾或全库抽取。

同一讨论仅凭共享原消息引用追加新证据，保持稳定 ID 和旧证据修订；不会凭同人、时间或语义相似合并具体事情。最多七段讨论、每段八条引用、三个话题，保留原已纳入记录及人工决定。容量已满或引用重叠到两段记录时，保留独立输入，coverage.incremental.deferred_discussions 显示未纳入数量；用户缩小所选范围后更新。没有自动分页、淘汰审核记录或隐藏的全历史任务。

自动签到成功、积分奖励等通知，若只有签到、点赞等常规命令且没有实际讨论或事项依据，不进入重要记忆；真实求助仍可准入。判断只针对内容，不标记联系人类型。促销与未解析图片规则、安全投影和原文定位继续复用；后来有实际询价时重新检查完整讨论上下文。

泛标题优先使用有有效内容的原句，跳过图片占位、表情与孤立 URL 作为标题首选。孤立号码或账号/访问字符串在记忆输出中省略，来源引用和原消息保留；同步旧修订与手机旧缓存也应用相同投影。所有标题和概述仍为证据文字，不能据此推断执行行为或完成状态。
