## 3. V3.0-A 交付边界

- canonical JSON Schema：ID、UTC 时间、时区、revision、状态、错误、分页、
  `RecordingSession`、`AudioAsset`、`ProcessingRun`、`Utterance`、`DeviceSync`；
- Desktop `/api/v3/*` 与 Device `/device/v3/*` OpenAPI 3.1 骨架；
- Python、Vue、ArkTS 对同一 canonical fixture 的解码规则和未来 enum 降级；
- 默认关闭的 V3 feature flag 与不接触数据库/端口的空 composition root；
- production Passkey RP ID/origin 注入方式和占位值拒绝门禁；
- ADR-0001/0002，锁定契约源、API 权限边界和并行切换策略。

V3.0-A 不创建 V3 Core schema、不导入 V2 数据、不实现 Device sync handler，也不
替换任何 V2 默认页面/命令。这些分别属于 V3.0-B、C、E/F。
