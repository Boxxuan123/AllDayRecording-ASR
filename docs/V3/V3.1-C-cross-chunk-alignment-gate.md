## 为什么不能只看普通 CER 或 DER

普通整段 CER 可能掩盖五分钟切片接缝处的漏字、重复字和时间漂移；全局说话人标签置换也可能掩盖同一人在相邻切片被重新编号。V3.1-C 只检查每个接缝前后默认 5 秒范围，并同时保留：

- reference 漏配率和多余 prediction 比率；
- 匹配话语起止边界的平均、P95 和最大绝对误差；
- 接缝范围聚合 CER 和 gross misalignment rate；
- 最优说话人映射后的 confusion rate；
- 同一 reference speaker 穿过接缝时的 track continuity error rate；
- 人工标记重叠讲话子集的独立错误率。

reference 与 prediction 使用会话毫秒坐标匹配，不依赖模型自己的 segment ID。prediction 必须列出 `source_chunk_ids`，因此收据能够追溯到参与拼接的原始切片。

## `v3.1-c.1` 准入策略

只有 alignment、transcript、speaker、overlap 四类真值都为 `exhaustive`，且所有接缝都经人工复核，才进入数值判断。默认门槛为：

| 条件 | 门槛 |
| --- | ---: |
| 已复核接缝 | 至少 10 个 |
| 接缝范围 reference utterance | 至少 30 条 |
| 重叠讲话 reference utterance | 至少 5 条 |
| 漏配率 / 多余率 / gross 错位率 | 各不高于 5% |
| 边界 P95 | 不高于 750 ms |
| 接缝 CER | 不高于 20% |
| 说话人 confusion / continuity error | 各不高于 5% |
| 重叠子集错误率 | 不高于 20% |

任何指标不可用也会形成 blocker。策略不允许调用者通过输入文件自行放宽；变更门槛必须发布新的 policy version。

## 可审计输入与收据

Canonical JSON Schema 位于 `contracts/v3/schemas/timeline-quality.schema.json`。输入包含 session、真值完整度、切片接缝、reference utterance、prediction utterance 和非敏感 metadata。运行：

```powershell
allday-asr seam-audit .\timeline-audit.json --output .\timeline-audit.receipt.json
```

命令使用 canonical JSON 计算 `input_sha256`，将策略、所有指标、blocker 和 accepted/rejected 决策写入收据，再对不含自引用哈希的收据主体计算 `receipt_sha256`。拒绝时仍写出完整收据并返回退出码 2，适合 CI 或发布脚本 fail closed。
