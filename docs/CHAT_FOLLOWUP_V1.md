## 使用入口

按原有方式重启 Windows 工作台后，打开侧栏“跟进事项”（`/followups`）。本次没有停止或重启正在使用的工作台。首次正常启动执行内部迁移 31/32，并从受控本地交付包及相关性审核文件离线应用候选。修订 2 的固定十条全部留在个人范围之外；导入只用已取得的响应，不增加推理、真实提醒或对外消息。首屏最多 15 项，继续加载会保留其他候选。

- “需要我处理”：明确归到本人且有实际承诺；“等对方”：明确由对方处理且存在关系。
- “已相关 / 待明确”：已证明个人相关、但责任或时间仍需解释的事项。未建立个人相关性的群聊不产生待审核卡；历史相关约定注明“进展未知”。
- “已结束”：完成、取消或忽略；只有明确操作才能重新开启。

卡片提供原话、来源发送时间、承担者、涉及账号、时间精度、最近处理时间和变化历史。可以查看原文上下文、确认归属、修改内容/日期/明确时间、完成、忽略和重新开启。不要把“刷新最近 7 天”和“重载列表”混淆：前者启动一次有限分析，后者只读取已有结果。

## 原范围、身份和时间

配置沿用原三个固定会话的稳定平台/采集账号/会话 ID，不按昵称重选。可以在“范围与本人身份”采用聊天查询中已启用的最多三个会话；更改范围会按正式快照初始化，接收游标仍由已验收的 ChatCache 管理。

用户已确认来源就是本人 QQ/微信导出的聊天。采集账号是登录/归档账号，发送者标识可能使用平台另一种格式；它们不直接相等，不能因此把全会话的人归为本人。在“从已选会话加载发送者”中选自己的账号，点击“这是我本人”；同名发送者不合并。已交付候选会立即用本地原响应重建归属，事件 ID 不变、人工修改优先，额外模型调用为零。还可直接在单条卡片确认由我处理或等对方。

来源时区目前未确认，默认未知，不以 Windows 时区推断。明确知道来源时区时填写 IANA 名称，例如 `Asia/Shanghai`，并保存范围配置。日期以原消息发送时间为准；日期级约定不会补出小时，夏令时重复/缺失的本地时间保留不确定性。人工可以自行明确日期或带偏移的准确时间。修订 2 的十条没有个人相关性正例，当前个人任务、已确认关注及待审核卡均为零。本人映射和时区仍缺，不按昵称猜测；C02 的好友条件仅留审核记录。

## 有界刷新、停止和恢复

每次用户显式刷新最多分析 1,000 条去重消息，包含相关已有证据/补取上下文；默认近期窗口 7 天、最多三个原会话，不启动常驻全库推理。每次最多 12 次模型调用、900 秒总模型窗口；单次最长 180 秒，最多一次尝试（不自动重试），单次请求 256 KiB，可见 prompt/指令/schema 的 UTF-8 字节限额 128,000。这不是完整 SDK 请求或 token 上限；完整 SDK/系统/工具开销仍未知，实际用量只引用回执。

接收/索引进度、事项分析水位和外部同步状态分别保存。一个 HTTP 页可能多收到一些消息，但模型工作集仍封顶 1,000；未分析范围、快照与断点保留，界面显示覆盖未完成。首屏和已有开放上下文的上限只限制显示/本次输入，不删除来源或任务。

“停止分析”取消本次有限作业。中断或预算耗尽会保留断点、失败批次和连续成功水位；“按原预算恢复”不会重置计数/期限。保存的模型响应可以在期限后本地应用，不能趁恢复发起超预算新调用；跨进程锁避免两处同时分析。失败缺口之前才算连续完成，不以扫描到最后一批冒充全部成功。没有响应可重放时明确报告不可继续，而不是制造空成功结果。

Mac/模型离线时，已缓存原文和已有事项、人工操作仍可用；需要远端补取的行为显示失败。源恢复/数据集变化清理可重建缓存，不清空人工应用状态。稳定事项键依据来源命名空间、原记录和原话位置；同证据重跑不复活忽略，后来独立承诺可形成新事项。

## 与录音任务和日历衔接

在“修改 / 关联录音任务”填写明确的已有录音事件 ID。关联后聊天证据加入原事件，录音证据保留，原提醒对象、候选和外部身份不换；相似标题不会触发关联。完成/改期通过原事件修订、提醒状态和同步投影更新同一对象，没有新日历写入器。

纯聊天候选在本阶段不自动创建手机提醒。关联已有任务后沿用既有提醒路径及人工授权；不把缺少时刻或历史线索变成日程。聊天来源真实手机 Calendar Kit 往返：NOT_RUN。手机、手表、Mac：NO CHANGE。

## 本地状态和隐私边界

Mac 来源缓存位于 `state/v3/chat/cache.sqlite3`；同一事件/人工状态位于 `state/v3/core.sqlite3`，新增来源关联、效果幂等和作业断点表不复制任务状态。内部数据库版本 32，手机契约版本不变。32 只新增按来源和证据绑定的准入审计，不新增个人任务副本。不要只凭刷新成功就删除 core 数据库或人物映射。

本轮私人原话、范围、响应和执行回执保存在 Git 忽略的 `state/chat-acceptance/followup-20261010`；正常启动用的本地候选包在 `state/v3/chat/followups/handoff-candidates.json`。二者均不入公开仓库。已有 `CHAT_DATA_BASE_URL` / `CHAT_DATA_TOKEN` 或本地 connection 配置继续使用，不在聊天或报告内发送凭据。
